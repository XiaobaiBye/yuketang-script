# Yuketang University Edition Userscript

[简体中文](./README.md) | [English](./README.en.md)

A browser userscript for university editions of Yuketang. It assists with video, audio, and courseware playback and offers optional question-bank and AI-powered answering. Available features depend on your school's version of the site. If a page changes or a question cannot be identified reliably, handle it manually.

**Do not enable both versions at the same time.** They store settings and progress separately, so you may need to reconfigure the script when switching versions.

## Features

- Assists with video, audio, and courseware playback and stores some learning progress.
- Decodes dynamic fonts on some assignment pages in the browser, with OCR as a fallback when decoding fails.
- Queries the ITIHEY question bank first. The platform may use its own AI when a question is not found; you can also configure a separate AI service as a fallback.
- Offers automatic submission and save-only modes. When an answer cannot be matched safely, the script stays on the page for manual review.
- Provides panel controls to start, stop, reload, clear cached data, and export diagnostics.

Some features only work in specific page flows. For example, certain assignment and exam pages under `pro/lms` do not support automatic answering. Seeing the script panel does not mean every feature is available on the current page.

## Question bank, costs, and accuracy

- Third-party question-bank service: [ITIHEY Console](https://platform.itihey.com/console/login). Based on the maintainer's experience, **CNY 1 covers roughly 100 question searches**. This is an estimate, not a fixed price; check the platform for current charges.
- **The recommended setup uses the question bank; a separate AI API is optional.** If the bank has no matching question, ITIHEY may try its built-in AI. The script's “Enable AI answering” option refers to a separately configured custom AI fallback. The code also supports custom-AI-only use, but that is not the recommended setup for this project.
- In the maintainer's experience, directly matched question-bank answers have been correct nearly 100% of the time, but accuracy is not guaranteed. Answers generated by the question-bank platform's AI can be wrong because of details such as Chinese book-title marks (`《…》`). The script displays the answer source (for example, “ITIHEY 题库”, “ITIHEY AI”, or “自定义 AI”); review answers yourself before submitting.

## Installation and use

1. Install a browser extension that supports userscripts, such as Tampermonkey or ScriptCat.
2. Open the script file linked above, copy its full contents, create a new script in the extension, and save it. Start with the stable version.
3. Open your school's Yuketang course page. The scripts declare matches for `*.yuketang.cn` and `*.gdufemooc.cn`; the page path must also be part of a supported workflow for specific features to work.
4. If you want answering features, register for the question bank in the [ITIHEY Console](https://platform.itihey.com/console/login). In the script panel, open **AI配置** (AI settings), enable the question bank, and enter your own API key. A separate AI service is an optional additional fallback. No answering configuration is needed if you only want the other features.
5. Click **开始刷课** (Start). Watch the panel log and manually review questions that the script cannot identify or answer reliably.

## Important notes

- Question-bank and AI services may require your own API keys and may charge fees. Never put a real API key in the script, commit it to the repository, or post it in a public issue.
- The script loads external resources and needs a network connection on first load. Changes to third-party APIs or the Yuketang page structure may break features.
- Automatic recognition and answering cannot guarantee correct results. Check your school's, course's, and platform's rules before use.
- You can export diagnostics from the panel when reporting a problem. Check the exported file for personal information before sharing it publicly.
