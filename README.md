# 雨课堂高校版脚本

面向雨课堂高校版页面的浏览器用户脚本，提供视频、音频和课件学习辅助，以及可选的题库与 AI 答题功能。实际可用功能取决于所在学校的页面版本；遇到页面改版或无法可靠识别的题目时，请以手动操作为准。

## 脚本版本

| 文件 | 版本 | 说明 |
| --- | --- | --- |
| [雨课堂高校版刷课脚本.js](./雨课堂高校版刷课脚本.js) | v1.1 | 日常使用的正式版 |
| [雨课堂高校版刷课脚本 测试版.js](./雨课堂高校版刷课脚本%20测试版.js) | v1.0-test.6 | 用于验证新功能的测试通道，可能不稳定 |

**正式版和测试版不要同时启用。** 两者分别保存配置和进度，切换版本后可能需要重新配置。

## 主要功能

- 辅助播放视频、音频及课件，并保存部分学习进度。
- 对部分作业页面的动态字体进行浏览器内还原；无法还原时尝试 OCR 识别。
- 可选接入 ITIHEY 题库；启用 AI 答题后，可在题库未返回有效答案时尝试 AI。
- 提供“自动提交”与“只保存答案”模式；无法安全匹配答案时会停留页面，供手动检查。
- 面板提供开始、停止、重新加载、清除缓存和导出诊断等操作。

部分功能仅在特定页面流程中实现。例如，`pro/lms` 的某些作业、考试页面目前不会自动答题；不要仅凭脚本面板出现就认为当前页面的全部功能可用。

## 安装与使用

1. 在浏览器中安装支持用户脚本的扩展，例如 Tampermonkey 或 ScriptCat。
2. 打开上方对应的脚本文件，复制完整内容，在扩展中创建新脚本并保存。建议先使用正式版。
3. 打开学校的雨课堂课程页面。脚本声明匹配 `*.yuketang.cn` 和 `*.gdufemooc.cn`；具体功能还需页面路径符合脚本支持的流程。
4. 如需题库或 AI 答题，在脚本面板点击“AI配置”，启用对应选项，填写你自己的 API URL、API Key 等信息并保存。不需要答题功能时可不配置。
5. 点击“开始刷课”。过程中留意面板日志；遇到识别失败或需要人工确认的题目，请自行检查和处理。

## 注意事项

- 题库和 AI 服务通常需要自行申请密钥，可能产生费用；不要把真实 API Key 写入脚本、提交到仓库，或放进公开的 issue。
- 脚本依赖外部资源，首次加载需要网络连接；第三方接口和页面结构变化都可能影响功能。
- 自动识别与自动作答不能保证正确。使用前请确认符合学校、课程及平台的相关规定。
- 反馈问题时可使用面板的“导出诊断”功能，但公开分享前仍请自行检查其中是否含有个人信息。
